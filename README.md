# Decode Labs Data Analytics Projects

This repository contains my data analytics projects completed during the Decode Labs program. The projects demonstrate my practical application of data cleaning, exploratory data analysis, Excel analysis, SQL querying, and data-driven insights.

## Projects

### Project 1: Data Cleaning and Preparation

This project focuses on preparing an e-commerce dataset for analysis.

Key activities include:
- Data cleaning and preparation
- Identifying and handling missing values
- Checking data consistency
- Reviewing data types and structure
- Preparing the dataset for analysis

**Tool:** Microsoft Excel

---

### Project 2: Exploratory Data Analysis and Business Insights

This project builds on the cleaned dataset and focuses on exploratory data analysis and extracting meaningful business insights.

Key activities include:
- Exploratory data analysis
- Descriptive statistics
- Pivot table analysis
- Revenue analysis
- Product performance analysis
- Payment method analysis
- Order status analysis
- Data visualization

The analysis was used to identify patterns and trends across products, revenue, quantities, payment methods, and order statuses.

**Tool:** Microsoft Excel

---

### Project 3: SQL Data Analysis

This project applies SQL to analyze the same dataset and answer business-related questions using database queries.

Key activities include:
- SQL data querying
- Filtering and sorting data
- Aggregation functions
- GROUP BY analysis
- Average and total calculations
- Product-level analysis
- Business-oriented data exploration

**Tool:** Microsoft SQL Server
